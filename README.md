# Portfolio Website

![Portfolio screenshot](images/portfolio.png)

## Features

- One-page layout with a top menu that scrolls to each section
- Moving strip of tool logos
- Light and dark mode button (remembers your choice)
- Sections for skills, education, projects, guides and contact
- Works on phones and computers
- Contact form
- Plain HTML, CSS and JavaScript, no frameworks

## Built with

- HTML
- CSS
- JavaScript

## Folder structure

```
portfolio/
├── index.html      # the page content
├── style.css       # colors and design
├── script.js       # light/dark mode and the moving strip
├── resume.pdf      # my resume
├── images/         # photo, project screenshots and skill logos
└── guides/         # PDF guides I wrote
```

## How to run

1. Download or clone this repository.
2. Open the folder.
3. Double-click `index.html`. It opens in your browser, and no installation is needed.

## How to change it for yourself

- **Text:** edit `index.html`
- **Colors:** change the color values at the top of `style.css`
- **Photo and screenshots:** put your images in the `images` folder
- **Contact form:** make a free form at formspree.io and put your form link in the `action` of the form in `index.html`
